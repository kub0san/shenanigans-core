# No cursed-energy (mana) resource

The plugin has no cursed-energy bar, cost, or regeneration gate. It was removed deliberately:
casting is gated by cooldowns and the ability rail, not by a consumable resource, and all
gameplay values are hardcoded constants rather than configurable costs. Do not reintroduce a
mana/CE system — it would require new UI, persistence, and balance rules that the current
design intentionally avoids.
